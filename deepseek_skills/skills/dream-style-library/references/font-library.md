# 原创字体大目录（references）—— 实际 950 款（目标 ~1924，宁缺毋滥未虚构）

> 用途：全量字体检索目录（与 font-pairings.md 的"搭配"互补：本库查字体、搭配库查组合）。
> 数据原则：全部为**真实存在**的 Google Fonts 开源字体 / 系统内置字体 / 知名开源字体；分类与气质描述为 Dreamskills 原创撰写；字体名与来源为事实信息。
