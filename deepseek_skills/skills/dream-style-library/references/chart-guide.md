# 原创图表指南库（references）—— 25 种

> 用途：数据可视化选型与样式规范。全部为 Dreamskills 原创设计，功能对标 ui-ux-pro-max 的图表数据域规模，不复制其内容。
> 加载方式：由 dream-design-system / dream-perf-audit / dream-ui-polish 在涉及数据可视化时按需读取；先查"关键词索引"定位编号。

## 关键词索引（数据类型 → 编号）

| 关键词 | 编号 |
|---|---|
| 分类比较（柱/条/分组/堆叠） | 1–4 |
| 趋势/时间序列（折线/面积） | 5–6 |
| 分布/相关（散点/气泡/箱线/直方图） | 7–8, 23–24 |
| 占比/构成（饼图/环形图/树图/词云） | 9–10, 16, 25 |
| 多维/概览（雷达/仪表盘/热力/地图/KPI/子弹图） | 11, 15, 19–22 |
| 流程/流向（漏斗/瀑布/甘特/桑基/和弦） | 12–14, 17–18 |

## 1. 柱状图 Bar Chart
- 适用：分类数据比较（各月份销量、各部门人数）；类别 ≤12 个
- 不适用：时间跨度长且连续（用折线）；类别过多（转水平条形）
- 样式规则：从零基线起柱；柱宽 ≥ 柱间距 2 倍；数值标签在柱顶；单一主色 + 高亮强调一柱
- 常见错误：截断 Y 轴放大差异，误导读者

## 2. 堆叠柱状图 Stacked Bar
- 适用：总量 + 构成同时展示（各渠道贡献）；类别 ≤8、分段 ≤5
- 不适用：需精确比较单个分段（人类难以跨柱比高）
- 样式规则：同色相梯度分段；总量标签在柱顶；悬停显示分段明细；图例顺序与堆叠顺序一致
- 常见错误：分段颜色无梯度、顺序错乱

## 3. 分组柱状图 Grouped Bar
- 适用：两个及以上系列跨类别比较（分地区分季度）
- 不适用：系列 >4（视觉过载）；比较总量而非系列
- 样式规则：组内柱间距 < 组间间距（视觉分组）；系列用主色+accent+中性色；图例紧邻坐标轴
- 常见错误：组内组间间距相同，分不清层级

## 4. 条形图 Horizontal Bar
- 适用：类别名较长（部门名、地区名）；类别 >10 个
- 不适用：时间顺序展示（水平排列违反阅读习惯）
- 样式规则：类别名左对齐；数值标签在条末端；条高 ≥ 间距 2 倍；按数值降序排列（除非有自然顺序）
- 常见错误：未排序导致对比困难

## 5. 折线图 Line Chart
- 适用：时间序列趋势、连续数据变化（日活、股价）；多系列对比（≤5 条）
- 不适用：离散分类（用柱状）；>5 条线（会交织成麻）
- 样式规则：Y 轴尽量从零（趋势场景可非零但需标注截断）；数据点 ≤ 线宽 2 倍；主系列用主色加粗、次系列浅色；网格线用虚线弱化
- 常见错误：Y 轴非零且未标注，趋势被夸大

## 6. 面积图 Area Chart
- 适用：总量随时间的累积趋势、占比随时间变化（堆叠面积）
- 不适用：精确读数（面积难精确比较）；负值占比
- 样式规则：填充透明度 20–30%；堆叠面积需自下而上按序；基线从零开始；标签放末端峰值
- 常见错误：堆叠顺序与图例相反；填充过浓

## 7. 散点图 Scatter Plot
- 适用：两变量相关关系、异常点检测（价格×销量）
- 不适用：超过一个因变量序列（视觉混乱）；需精确趋势（辅助回归线）
- 样式规则：点径 4–6px、透明度 0.7（重叠可见）；坐标轴刻度稀疏；相关性说明文字放角落；可加趋势线与 R²
- 常见错误：点径过大互相覆盖

## 8. 气泡图 Bubble Chart
- 适用：三维数据（X、Y、大小）；规模对比 + 两维分布
- 不适用：大小维度精度要求高（面积难以精确比较）
- 样式规则：气泡面积与数值成正比（半径按面积开方，勿按半径线性）；气泡内不写字（标签在外）；图例给大小刻度
- 常见错误：半径按数值线性缩放导致面积夸张

## 9. 饼图 Pie Chart
- 适用：单序列占比，分段 ≤5 且无接近值（30% vs 31%）
- 不适用：多序列、需精确比较、分段多（一律转柱状/堆叠条）
- 样式规则：从 12 点方向顺时针起；分段 ≥5% 才标数值，否则合并"其他"；最大分段从 12 点起；对比度 ≥3:1
- 常见错误：分段过多、相近占比难以分辨

## 10. 环形图 Donut Chart
- 适用：占比展示 + 中心放总量/KPI；比饼图更易读
- 不适用：精确对比；分段 >6
- 样式规则：环宽 = 外径 25–35%；中心放总量与单位；分段间留 1–2px 间隙；悬停突出（外扩 4px）
- 常见错误：环过细或过粗；中心无信息浪费空间

## 11. 雷达图 Radar Chart
- 适用：多维度综合对比（能力模型、产品对比）；维度 ≤8
- 不适用：单系列、维度间无共同度量纲
- 样式规则：各维度刻度统一归一化（0–100%）；系列 ≤3；网格线 4–5 层；填充透明度 20%
- 常见错误：维度不归一导致形状失真

## 12. 漏斗图 Funnel Chart
- 适用：转化流程各环节（曝光→点击→转化）；环节 ≤6
- 不适用：比较总量（只关心单环节）
- 样式规则：梯形宽度与数值成比例；环节间标注转化率；当前环节用主色、其余中性色；可附流失原因
- 常见错误：环节过多梯形变细条

## 13. 瀑布图 Waterfall Chart
- 适用：增减变化分解（利润构成、现金流、预算差异）
- 不适用：非累计变化（用柱状）
- 样式规则：增减柱用语义色（增=success、减=danger 或统一主色+灰）；连接虚线；总计柱加深色；数值标签在柱顶
- 常见错误：增减色与语义约定不一致

## 14. 甘特图 Gantt Chart
- 适用：项目计划/任务时间线、依赖与里程碑
- 不适用：非时间维度排期
- 样式规则：横轴为日期、纵轴为任务；条块 = 工期，起点 = 开始日；今日线用主色竖虚线；里程碑用菱形；依赖用箭头
- 常见错误：今日线缺失，排期无参照

## 15. 热力图 Heatmap
- 适用：矩阵数据密度（用户活跃时段、相关性矩阵）；行列 ≤30
- 不适用：精确数值（颜色难读数）；维度超过两个
- 样式规则：单色相 5 级梯度（浅→深）或双色（低冷高暖）；数值标注只在格子 ≥24px 时显示；图例必带
- 常见错误：用彩虹多色梯度造成误读

## 16. 树图 Treemap
- 适用：层级占比 + 总量（磁盘占用、品类销售构成）
- 不适用：需精确比较面积；层级 >3
- 样式规则：面积与数值成正比；一级用色相区分、二级用明度；最小块 ≥ 可读尺寸，过小合并"其他"；标签字号随块大小降级
- 常见错误：最小块过小无法交互

## 17. 桑基图 Sankey Diagram
- 适用：流量/能量流向（用户路径、资金流转、能源）
- 不适用：非流向关系；节点 >20
- 样式规则：流带宽度与流量成正比；同源节点同色；流带透明度 0.7 以便交叠可见；节点标签避免遮挡
- 常见错误：流带色与节点色不一致

## 18. 和弦图 Chord Diagram
- 适用：多节点两两关系强度（人群迁移、通信往来）；节点 ≤15
- 不适用：单向流程（用桑基）；关系稀疏
- 样式规则：弧宽与关系强度成正比；节点环段色唯一；悬停高亮关联弧并淡化其余；图例可选
- 常见错误：节点过多变成"毛线团"

## 19. 地图 Map（等值区域/气泡地图）
- 适用：地理分布（省份销量=等值区域；城市规模=气泡）；区域 ≤50
- 不适用：非地理数据；区域过细导致色阶无意义
- 样式规则：等值区域用单色相 5 级梯度；气泡半径按面积开方；地理轮廓细线弱化（border 色）；图例 + 数值悬停提示
- 常见错误：梯度无图例或图例与实际不符

## 20. KPI 卡 KPI Card
- 适用：核心指标总览（营收、DAU、转化率）
- 不适用：需要趋势/分布细节（转小图）
- 样式规则：大数字（等宽字体）+ 指标名 + 环比/同比（箭头 + 语义色）+ 迷你 sparkline（可选）；数字 ≥ 28px
- 常见错误：数字无单位、无对比基准

## 21. 仪表盘/仪表图 Gauge
- 适用：单指标阈值状态（健康分、目标进度）；0–100 类区间
- 不适用：多指标并列（转 KPI 卡）；精确读数（指针位置难读）
- 样式规则：半圆 180°；阈值分段色（如绿/黄/红）但默认中性为主；指针或弧形填充表达当前值；中心放大数字
- 常见错误：色段过多（>3）变成红绿灯迷宫

## 22. 子弹图 Bullet Chart
- 适用：实际 vs 目标 vs 分档（预算执行、KPI 达成）；横向紧凑
- 不适用：需要标准柱状对比多个分类
- 样式规则：背景分档（浅→深 3 层）；目标线为深色短竖线；实际值为粗条；标签在图左侧
- 常见错误：分档与目标线视觉层级颠倒

## 23. 箱线图 Box Plot
- 适用：分布特征（中位数、四分位、异常值）；组间分布对比
- 不适用：非统计受众（改用直方图/小提琴图更直观）
- 样式规则：箱体 = IQR、中位线加粗、须线 = 1.5×IQR、异常点为独立圆点；组间同宽；颜色单色即可
- 常见错误：须线长度误画为 min/max

## 24. 直方图 Histogram
- 适用：单变量分布（年龄分布、响应时延）；分组为连续区间
- 不适用：分类数据（用柱状图）；需精确区间边界
- 样式规则：柱间无间隙（连续区间）；组数 = 数据量开方左右（如 1000 条 → 约 20–30 组）；单色填充；标注均值线
- 常见错误：分组过细呈锯齿或过粗丢失分布

## 25. 词云/网络图 Word Cloud / Network
- 适用：词频概览（评论高频词）；实体关系网络（知识图谱、好友关系）
- 不适用：精确量化（字号难比较）；词云用于严肃报告（建议转条形图）
- 样式规则：词云：字号按频次对数缩放、颜色 2–3 种、低频词 ≤2 个；网络图：节点大小=权重、边宽=关系强度、布局避免节点重叠、≥8px 可点击热区
- 常见错误：词云字号线性缩放导致极端差异；网络图节点过密不可交互
