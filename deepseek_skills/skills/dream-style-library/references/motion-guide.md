# 原创动效模式库（references）—— 16 种

> 用途：动效选型与规格。全部为 Dreamskills 原创设计，功能对标 ui-ux-pro-max 的动效数据域规模，不复制其内容。
> 加载方式：由 dream-design-system（动效 tokens）与 dream-ui-polish（pro-rules 动效节）在涉及动效时按需读取；先查"关键词索引"定位编号。
> 全局纪律：动效只服务反馈与引导；时长 150–300ms；进入 ease-out、过渡 ease-in-out、消失 ease-in；尊重 prefers-reduced-motion（见第 16 条）。

## 关键词索引（场景 → 编号）

| 关键词 | 编号 |
|---|---|
| 进入/离开（淡入/滑入/缩放/展开折叠） | 1–4 |
| 过渡/衔接（共享元素/骨架/页面转场） | 5, 9, 13 |
| 反馈（弹性/悬浮抬升/水波/脉冲/进度） | 6, 10–12, 14–15 |
| 强调/叙事（视差/交错/数字滚动） | 7–8, 14 |
| 无障碍（降级模式） | 16 |

## 1. Fade 淡入淡出
- 时长/缓动：150–250ms，ease-out（入）/ ease-in（出）
- 适用：弹层、toast、状态提示的进入/离开；任何"轻量出现/消失"
- 实现要点：opacity 0→1（1→0）；与位移组合时位移 ≤8px（避免廉价感）；opacity 动画走 GPU 合成层
- 反模式：仅靠 fade 表达层级关系（无空间感，易误读为"内容替换"）

## 2. Slide 滑入
- 时长/缓动：200–300ms，ease-out（入）/ ease-in（出）
- 适用：抽屉、侧边栏、底部弹层、从触发方向进入的面板
- 实现要点：位移 ≤视口 1/3；从触发元素方向滑入（如按钮在右 → 面板从右）；transform: translateX/Y；带 0.2 秒的"顺滑首帧"防卡顿
- 反模式：位移距离过大或方向与触发点无关（用户丢失空间参照）

## 3. Scale 缩放
- 时长/缓动：150–200ms，ease-out；弹窗带 overshoot（1.03）再回 1
- 适用：模态框、tooltip、popover 的进入；强调元素的出现
- 实现要点：transform: scale(0.92→1) + opacity 同步；缩放中心 = 触发点（transform-origin）；overshoot 仅用于 1 次（弹簧感 1 次即可）
- 反模式：缩放中心固定左上角，与触发点无关；多次 overshoot 显得抖

## 4. Expand/Collapse 展开折叠
- 时长/缓动：200–300ms，ease-in-out
- 适用：手风琴、展开详情、折叠面板、树节点
- 实现要点：优先用 grid-template-rows / max-height 过渡（避免读布局）；内容淡入延迟 50–100ms；方向保持单一（只纵向或只横向）
- 反模式：同时展开/折叠多块互相挤占，布局跳动

## 5. Shared Element 共享元素
- 时长/缓动：250–350ms，ease-in-out；两个端点（列表缩略图→详情大图）
- 适用：图片/卡片从列表进入详情的连续过渡；多步骤流程的位置延续
- 实现要点：两端元素在视觉上"同一主体"（用同一图/同一卡片）；中间态用绝对定位 + transform 插值；保证开始/结束帧与两端 100% 一致
- 反模式：两端视觉不一致（尺寸、圆角、颜色突变），用户以为元素变了

## 6. Spring 弹性
- 时长/缓动：200–400ms，spring（stiffness≈180–240, damping≈20–28），不用时长缓动
- 适用：按钮按压回弹、列表项"归位"、拖拽释放、通知滑出回弹
- 实现要点：仅用于"物理感"场景（按/拖/放）；一次回弹即止（damping 足够大防持续振荡）；transform 驱动
- 反模式：对文字/表格等静态内容施加弹性（干扰阅读）

## 7. Parallax 视差
- 时长/缓动：滚动驱动（随滚动位移），无固定时长；缓动随滚动速度
- 适用：营销页 hero 背景、品牌叙事长页、产品展示
- 实现要点：前景/背景位移速率比 1.2–1.5:1（克制）；仅 transform 位移；移动端关闭或降级为淡出；性能敏感页面慎用
- 反模式：位移比过大造成眩晕；非品牌页滥用拖慢滚动

## 8. Stagger 交错
- 时长/缓动：每条 150–250ms，ease-out；相邻延迟 40–80ms
- 适用：列表逐项进入、网格卡片依次浮现、步骤条
- 实现要点：条目按视觉顺序（行优先）编排延迟；总时长 ≤600ms；入场方式统一（同 fade 或同 slide）；列表重排时不做交错
- 反模式：延迟过长像"排队进场"；每次交互都触发交错（应只入场一次）

## 9. Skeleton 骨架过渡
- 时长/缓动：骨架闪动 1.2–1.6s 循环；到内容的过渡 150–200ms ease-out
- 适用：数据加载占位（列表、卡片、详情页）
- 实现要点：骨架形状与真实内容同构（同布局）；加载完成 fade 替换而非跳变；循环闪动用 opacity 0.6→1 渐变
- 反模式：骨架与真实内容布局不一致，加载后页面跳动

## 10. Progress 进度
- 时长/缓动：连续型 300ms ease-out 每段；不定型（indeterminate）循环 1.2s
- 适用：上传/下载、表单提交、页面加载进度条
- 实现要点：进度跳变处用缓动补间（不硬跳）；完成后 100% 停留 ≥200ms 再消失；失败态转语义色并停留
- 反模式：进度条"回退"或凭空跳动，用户信任崩塌

## 11. Hover Lift 悬浮抬升
- 时长/缓动：150–200ms，ease-out；离开 150ms ease-in
- 适用：卡片、按钮、列表项的 hover 反馈
- 实现要点：transform: translateY(-2px) + 阴影加深（sm→md）；位移 ≤4px 克制；必须与 active 态（按压缩回）配套
- 反模式：抬升过大像"飘起来"；触屏设备无 hover 时无替代反馈

## 12. Ripple 水波
- 时长/缓动：350–500ms，ease-out；从点击点扩散
- 适用：Material 风格按钮/列表项的点击反馈
- 实现要点：波纹半径 = 触发元素外接圆；从触点坐标发起；波透明（主色 12%）；点击结束立即开始收缩
- 反模式：波纹起点固定在中心（与触点无关）；非 Material 风格硬套水波

## 13. Page Transition 页面转场
- 时长/缓动：200–300ms，ease-in-out；整页
- 适用：路由/页面切换、Tab 切换（内容区）
- 实现要点：转场方向与导航方向一致（前进 = 左滑入，返回 = 右滑入）；过渡期间防双滚动；首屏首次加载不转场
- 反模式：每个路由都全屏转场（像 PPT）；转场遮罩吞掉交互

## 14. Count-up 数字滚动
- 时长/缓动：500–1200ms，ease-out（先快后慢）
- 适用：KPI 数字进入、统计看板、排行榜数字
- 实现要点：数值用整数步进（可加千分位）；触发条件：进入视口 75% 时启动（IntersectionObserver），不自动循环；终值精确落位
- 反模式：每次滚动/重渲染都重播；时长超过 1.5s 用户等不及

## 15. Attention Pulse 脉冲提醒
- 时长/缓动：脉冲 1.6–2.4s 周期，每周期 2 次；单次 150–300ms
- 适用：未读红点/铃铛提醒、需引导的新功能入口、危险操作警示
- 实现要点：scale 1→1.15 或 opacity 0.6→1 循环 2 次即停（或持续到首次点击）；脉冲元素 ≤1 处/屏；配 aria-live 提示
- 反模式：无限循环闪烁形成骚扰；多元素同时脉冲

## 16. Reduced Motion 降级模式
- 时长/缓动：N/A（关闭或替换）
- 适用：prefers-reduced-motion: reduce 用户、低电量模式、弱网
- 实现要点：媒体查询关闭位移/缩放/循环动效，保留 opacity 过渡（信息不消失）；重要状态变化用文字/图标补偿；动效开关（设置项）默认可关闭
- 反模式：仅降速不关闭（仍引发眩晕）；关闭动效后状态反馈缺失（如无 loading 提示）
