# 专业级打磨规则 Pro Rules（references）

> 本文件由 dream-ui-polish 的"步骤 4：细节质感"按需加载。
> 功能对等 ui-ux-pro-max 的 pro-rules 子技能：把资深设计师的高级细节规则编译成可执行条目；全部内容为 Dreamskills 原创。

## 1. 动效设计（Motion）

- **时长与缓动**：微反馈 150–200ms；面板/路由过渡 200–300ms；进入 ease-out、过渡 ease-in-out、消失 ease-in。
- **位移优先**：动效优先用 transform（位移/缩放/透明度），避免 layout 属性动画（重排成本高）。
- **距离感知**：弹层从触发点方向滑入（≤16px 位移），不搞"从天而降"。
- **克制原则**：一个页面同时动画元素 ≤3 处；动效只解释"从哪来、到哪去、发生了什么"。
- ✅ 按钮 hover 微抬 1–2px + 阴影加深；❌ 全站滚动入场动画、无限循环装饰动画。

## 2. 数据可视化（Data Viz）

- **色板**：主序列用同一色相不同明度（monochrome ramp），对比序列用 DESIGN.md accent；语义色只用于正/负/告警。
- **对比度**：图表元素与背景对比 ≥3:1；文字标注 ≥4.5:1。
- **标注**：坐标轴刻度稀疏（4–6 个）、数字等宽字体、单位与图例完整。
- ✅ 图例就近、hover 高亮整组；❌ 彩虹色板、3D 饼图、双 Y 轴滥用。

## 3. 深色模式（Dark Mode）

- **表面层级**：用明度分层而非纯黑——surface #0E1320 类深蓝灰、抬升层 +8% 明度、悬浮层 +16%。
- **降饱和**：品牌色在暗底降饱和 10–20%，避免霓虹刺眼。
- **阴影失效**：暗底用边框提亮（border 明度 +20%）与微弱光晕替代阴影。
- **图片处理**：亮图加暗遮罩（16–32%）；图标/插图用双套资源或 CSS filter。
- ✅ 切换动画 150ms 平滑过渡；❌ 纯黑背景、亮色大字块、暗底亮阴影。

## 4. 状态设计（Empty / Loading / Error / Success）

- **Empty**：说明 + 一个主行动（按钮）+ 轻插图；❌ 空白页或大图占位。
- **Loading**：骨架屏（形状与内容同构）优先于 spinner；>1s 给进度暗示；>4s 给文案说明。
- **Error**：说人话（发生了什么）+ 可行动（重试/回退）+ 错误详情折叠；❌ 只弹"系统错误"。
- **Success**：内联确认（toast/横幅）为主，整页成功页仅用于流程终点；toast ≤3s 可手动关闭。

## 5. Hero 区布局模式（6 种，按产品选一）

1. **居中宣言**（SaaS/官网）：标题+副标题+双按钮居中，下配产品截图；
2. **左文右图**（工具/详情）：左 5 右 7 分栏，图文对齐基线；
3. **沉浸全屏**（品牌/发布）：全屏视觉+底部渐隐标题，需注意加载性能；
4. **表单内嵌**（转化优先）：标题句 + 表单卡右置，注册/试用场景；
5. **数据证明**（B2B）：大数字指标带 + 客户 logo 墙，建立信任；
6. **滚动叙事**（故事型）：分屏滚动讲 3 步价值，适合新品介绍。
- ✅ 主行动 ≤2 个、视觉重心唯一；❌ 标题+轮播+表单+弹窗全塞满。

## 6. 间距节奏进阶（Spacing Rhythm）

- **节奏单元**：间距取 8pt 刻度的等比子集，同层级间距严格一致（卡片间 16、区块间 32–48）；
- **垂直韵律**：标题距其内容 8，距上文 32（"就近原则"——关联近、隔离远）；
- **密度开关**：数据型产品提供紧凑/舒适两档密度，只改组件内边距不动布局。

## 7. 微交互与图标

- **hover/active/focus 三态**：hover 明度 +8% / active 明度 −8% / focus 用 primary 2px 外圈（与 hover 区分，不可只靠颜色）；
- **图标系统**：同源同网格（24 网格、2px 线宽、圆角端点统一）；语义图标配文字标签；
- ✅ 图标按钮有 tooltip/aria-label；❌ 混用实心/线性图标、按钮只有图标无标签。

## 8. 响应式进阶

- **内容优先断点**：按内容折叠点定断点（sm 640 / md 768 / lg 1024 / xl 1280 为默认起点，可调）；
- **栅格降级**：桌面 12 栏 → 平板 8 → 手机 4/堆叠；表格移动端转卡片或横向滚动；
- **触控目标**：≥44×44px（移动端）；表单在移动端自动放大输入字号防 iOS 缩放。

## 9. 性能友好

- 动画只用 transform/opacity（GPU 合成层）；will-change 克制（只对真实高频动画元素）；
- 图片懒加载 + 宽度自适应 srcset；字体用 font-display: swap + 子集化；
- 首屏避免大图/视频自动播放；装饰动画在低电量模式（prefers-reduced-motion）全部关闭。

## 10. 组件形态规格（Component Specs）

- **按钮**：高度 40px（lg 48 / sm 32）；primary 实底 / secondary 描边 / ghost 透明三档；文字 ≥14px、圆角 radius-md；危险操作用 danger 语义色；
- **输入框**：高度 40px；label 置于输入框上方（勿用 placeholder 代替）；错误态 danger 描边 + 具体说明文字；前缀/后缀图标垂直居中对齐；
- **卡片**：内边距 24、圆角 radius-md、阴影 sm；卡片内不再嵌套卡片（用分区/分割线代替层级）；
- **弹窗/抽屉**：遮罩 rgba(15,23,42,.4)；圆角 radius-lg、阴影 lg；标题 18px + 关闭按钮；ESC 关闭 + 焦点锁定 + 背景滚动锁定；
- **导航**：顶部 64px、侧栏 240–280px（可折叠 64px 图标栏）；选中态 primary 文字色 + 指示条，hover 态 surface-alt；
- **表格**：表头 13px 半粗；行高按密度档 48/40/32；hover 必选、斑马纹可选；数字右对齐 + 等宽数字；
- **标签/徽章**：圆角 full、内边距 6/10、字号 12px；中性灰打底、语义色仅用于状态；
- **开关/标签页**：状态切换用 100–150ms 过渡；开关需明确开/关标签（勿只靠颜色）。

## 11. 排版进阶（Typography Pro）

- 层级三档（标题 24–32 / 正文 16 / 辅助 12–14）+ 明确的垂直间距节奏；标题换行人工控制（max-width/断行点）；
- 数字与表格用 tabular-nums；长文 max-width 60–75 字符；中文标题勿用两端对齐；
- 强调用字重+颜色而非下划线（链接除外）；删除线仅表"已取消"语义。

## 12. 打磨顺序（Order of Operations）

1 布局网格 → 2 间距节奏 → 3 色彩层级 → 4 排版 → 5 组件状态 → 6 动效微交互 → 7 响应式/深色 → 8 图标插画统一 → 9 数据可视化 → 10 性能复查。每步只动 DESIGN.md token 派生值，逐步截图对比（改前/改后），避免"越改越花"。
