# 无障碍（WCAG AA）关键项清单（references）

> 本文件由 dream-ui-polish 在响应式/无障碍检查时加载。关键项必须通过；完整审计可用 axe / Lighthouse 自动检查补充。

## 1. 文本对比度

- 正文/次级文字对背景 ≥4.5:1；大文本（≥18.66px 粗体或 ≥24px）与 UI 组件 ≥3:1；
- 检查：用取色工具对比，或运行 axe 自动检查。

## 2. 焦点可见

- 所有可交互元素有可见 focus 指示（focus ring 用 tokens primary，对比 ≥3:1）；
- 检查：Tab 键走查全页面，确认焦点位置清晰。

## 3. 语义与结构

- 标题层级按 1→6 递进不跳级；列表用 ul/ol；按钮用 button、链接用 a（语义正确）；
- 检查：查看 DOM 结构或读屏抽查。

## 4. 键盘可达

- 所有功能可通过键盘完成（无鼠标陷阱）；弹窗关闭、下拉选择均可键盘操作；
- 检查：纯键盘走完关键流程。

## 5. 表单标签

- 每个输入控件有可见 label 或 aria-label；错误提示与控件关联（aria-describedby）；
- 检查：逐个表单字段核对。

## 6. 动效与眩晕

- 尊重 prefers-reduced-motion；无频闪（闪烁 ≤3 次/秒）；
- 检查：开启系统"减弱动态效果"后页面仍可用。

## 7. 图片与图标

- 信息性图片有 alt；装饰性图片 alt=""；纯图标按钮有可访问名称（aria-label）；
- 检查：读屏抽查或查看代码。

## 8. 触控目标（移动端）

- 触控目标 ≥44×44px（间距补偿亦可）；相邻目标间距 ≥8px；
- 检查：移动断点点击走查。

## 9. 状态与通知

- 表单错误、加载、成功等状态有非纯颜色提示（文字/图标伴随）；
- 检查：错误场景、加载场景走查。

## 10. 达标记录

- 自检结果（通过/豁免）写入打磨记录；注明 automated（axe）与 manual 各自的覆盖项。
