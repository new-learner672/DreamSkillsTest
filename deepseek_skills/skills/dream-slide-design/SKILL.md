# 幻灯片设计（dream-slide-design）

> 定位：设计层的专项技能，对标 ui-ux-pro-max 的 ckm:slides 子技能（功能对等、内容原创）。把演示文稿从"文字堆砌"变成"有节奏的视觉叙事"。
> 吸收思想：ui-ux-pro-max ckm:slides（幻灯片专项设计）+ anthropics frontend-design（结构化规范）+ dream-design-system（tokens 契约）。

## 何时使用（触发条件）

- 演示文稿设计：产品介绍、方案汇报、教学课件、发布会、项目复盘、融资路演；
- 用户说"设计幻灯片/做演示文稿/汇报 PPT/讲课课件"。

不适用：长文文档排版（用 Markdown/文档模板）、网页设计（走 dream-design-system / dream-ui-polish）、单张宣传图（走 dream-banner-design）。

## 核心原则

1. **每页一个焦点**：一页只说一件事；其余信息降级为备注或附录。
2. **视觉节奏**：封面 → 目录 → 章节过渡 → 内容 → 图表 → 结尾的固定叙事骨架，避免"全是内容页"的平铺。
3. **少字大字**：标题 36–48px、正文 ≤5 行/页；听众读的是你讲的，不是屏幕上的字。
4. **tokens 派生**：配色/字体/间距全部引用 DESIGN.md，不引入新硬编码；页型只做结构，不做花哨装饰。
5. **数据图表化**：数字用图表/大数字指标呈现，不复制表格。

## 工作流程

### 步骤 0：读取强度模式

- 读取 `.dreamspec/SKILLS.md`，确定 rigorous / balanced / light 裁剪范围。

### 步骤 1：确认场景与结构（输入）

- 询问/确认：场景（内部汇报 / 对外方案 / 发布会 / 教学）、受众、时长（决定页数：1 页 ≈ 1–2 分钟）；
- 与用户确认大纲（章节 ≤6 个），产物：大纲 + 页数估算。

### 步骤 2：定版式系统（动作）

- 16:9 十二栏网格；定义三类母版：标题页、章节过渡页、内容页（含图表变体）；
- 从 dream-style-library 风格方向（若项目 DESIGN.md 无方向）确认视觉基调。

### 步骤 3：逐页设计（动作）

- 按页型模式库（references/slide-patterns.md）选型：封面/目录/章节/两栏/三卡/大数字/时间线/对比/图表/引用/结尾；
- 每页：一个主标题（≤8 词）+ 少量正文 + 一个视觉元素；图表页用"大图表 + 一句结论"；
- 中文排版：标题勿两端对齐、正文行高 1.5、标点避头尾悬挂（按渲染器能力）。

### 步骤 4：打磨与检查（产物）

- 快速反 slop 自检（参照 dream-ui-polish 清单：留白/层级/色彩克制）；
- 对比度抽查（正文 ≥4.5:1）；所有图片有替代说明；
- 产物：演讲者备注（每页 2–4 句）、生成记录。

### 步骤 5：输出（产物）

- 推荐可编辑源文件：HTML（reveal.js / Marp，易于版本管理与 Web 分享）或 PPTX；
- 幻灯片尺寸 16:9（教学 4:3 按需）；附件导出 PNG 预览图供 review 用。

## 验收标准

- [ ] 大纲与页数已与用户确认；章节 ≤6
- [ ] 每页一个信息焦点；无"整页文字"页
- [ ] 封面/目录/章节/内容/图表/结尾节奏完整（light 模式可省略目录与章节页）
- [ ] 配色/字体/间距全部引用 DESIGN.md tokens，无硬编码
- [ ] 图表页有结论句；数字非表格堆砌
- [ ] 演讲者备注已写；对比度抽查通过
- [ ] 输出为可编辑源文件（HTML/PPTX）+ 预览图

## 与其他技能的衔接

- 上游：dream-design-system（tokens）、dream-style-library（风格方向，可选）
- 下游：dream-review / dream-verify（验证门：产物与 tokens 一致、可打开渲染）
- 验证：light 模式冒烟（源文件可渲染）即可
- 强度模式：rigorous 全套页型 + 演讲者备注；balanced 标准节奏；light 简化骨架
