# 页型模式库（slide-patterns · references）

> 本文件由 dream-slide-design 逐页设计时按需加载。页型 = 版式模板 + 字号建议 + 避坑。所有数值基于 16:9 大屏（1920×1080 基准）与 DESIGN.md tokens。

## 1. 全局版式系统

- 网格：16:9 十二栏网格；页边距 64px；内容区最大宽 1600px；
- 字号阶梯（16:9 大屏）：巨幕标题 60–72 / 页标题 40–48 / 副标题 24–28 / 正文 16–18 / 注释 12–14；
- 留白：页边距 64；块间距 32；标题与正文间距 16–24；
- 母版三件：标题页（全屏视觉焦点）、章节过渡页（编号+标题+一句导语）、内容页（标题栏+内容区+页脚页码）。

## 2. 页型清单（12 种）

### 封面页（Opening）
- 版式：居中或左对齐；品牌 logo 左上；主标题 60–72 + 副标题 24 + 日期/主讲人 14；
- 避坑：不要把整段简介放封面；背景用 DESIGN.md 主色或风格库视觉，禁用杂乱渐变。

### 目录页（Agenda）
- 版式：章节编号（01-06）大号 + 标题左对齐列表；或网格卡片式；
- 避坑：不要超过 6 项；不写展开说明（留给对应章节）。

### 章节过渡页（Section Divider）
- 版式：超大编号 + 章节标题 + 一句导语；整页留白为主；
- 作用：呼吸感与叙事节奏的锚点，每 2–4 个内容页插一页。

### 两栏内容页（Two Columns）
- 版式：左文右图（或反之），6:6 或 7:5 分栏；图文基线对齐；
- 文字 ≤5 行；图含一句说明（caption）。

### 三卡页（Three Cards）
- 版式：三张等宽卡片（间距 32），每卡=图标+标题+1–2 行说明；
- 避坑：卡片不要都塞满文字；图标统一出自同一体系。

### 大数字指标页（Big Numbers）
- 版式：2–4 个大数字（≥72px，tabular-nums）+ 每数字一句说明 + 来源脚注；
- 用途：成果汇报、融资路演、数据证明；数字用 DESIGN.md 强调色点缀。

### 时间线页（Timeline）
- 版式：水平或垂直时间线；节点=年份/阶段 + 标题 + 一句说明；
- 避坑：节点 ≤6 个；时间线线条用中性色，节点用主色。

### 流程/架构图页（Flow & Architecture）
- 版式：从左到右或自上而下的流程；统一形状（圆角矩形）+ 统一箭头；
- 层级 ≤3 层；每节点 ≤5 字标签 + 详细放备注。

### 对比页（Comparison）
- 版式：左右对照表/双栏（旧 vs 新 / A vs B）；差异项用强调色标出；
- 避坑：不要用整页 Excel 式表格；只列 3–5 个关键对比维度。

### 图表页（Chart）
- 版式：大图表（占内容区 2/3）+ 一句结论（占 1/3 右侧）；
- 图表规则：见 pro-rules 数据可视化节（monochrome ramp + 单一强调色、直接标注、形状+颜色双编码）；
- 避坑：不要让听众自己读图——结论句必须由你讲出来。

### 引用页（Quote）
- 版式：超大引号 + 引文 32–40px + 出处 16；
- 用途：章节间过渡、观点强化；一页一引。

### 结尾/CTA 页（Closing & CTA）
- 版式：一句收束标题（40–48）+ 明确行动号召（联系方式/下一步/二维码）+ 感谢；
- 避坑：不要把结尾页塞满致谢名单（放附录）。

## 3. 数据与图表页规则

- 数据优先图表化：趋势→折线、占比→环形、对比→条形；禁止 3D 饼图与彩虹色板；
- 一个图表只讲一个结论；关键数据点直接标注数值；
- 表格出现在幻灯片里时：行数 ≤8、高亮关键行、数字右对齐。

## 4. 中文排版注意事项

- 标题不用两端对齐（避头尾悬挂问题，按渲染器能力处理）；
- 正文行高 1.5–1.6；中英文混排时西文用正文同族，数字用 tabular-nums；
- 引号/括号用全角（中文语境）；破折号前后不加空格；
- 字体：标题无衬线或按风格库搭配，正文默认 Noto Sans SC / 思源黑体，衬线风用 Noto Serif SC。

## 5. 输出与交付建议

- **HTML（推荐）**：reveal.js 或 Marp（Markdown 编写，Git 友好、可 Web 分享、可导出 PDF）；
- **PPTX**：可用 python-pptx 等生成结构化源文件（版式/字号/配色从 tokens 映射）；
- 每页配套演讲者备注（2–4 句，讲"结论与过渡"而非念稿）；
- 交付物：源文件 + PNG 预览图（供 dream-review / dream-verify 检查渲染效果）。
