# 横幅与营销视觉设计（dream-banner-design）

> 定位：设计层的专项技能，对标 ui-ux-pro-max 的 ckm:banner-design 子技能（功能对等、内容原创）。把"营销视觉"从随意拼图变成有焦点的转化工具。
> 吸收思想：ui-ux-pro-max ckm:banner-design（横幅专项）+ dream-design-system（tokens 契约）+ 广告设计最佳实践（单一焦点、CTA 明确）。

## 何时使用（触发条件）

- 横幅/营销视觉：Web Banner、社交媒体封面与帖子图、活动海报、App 开屏、广告图、电商主图；
- 用户说"设计 banner/做海报/营销图/开屏广告/社交封面/宣传图"。

不适用：演示文稿（走 dream-slide-design）、网页界面（走 dream-design-system / dream-ui-polish）、品牌 VI 系统（走 dream-design-system 提案流程）。

## 核心原则

1. **单一视觉焦点**：一张图只说一件事——一个产品/一个卖点/一个 CTA；其余元素服务焦点。
2. **一个 CTA**：明确的主行动（按钮/扫码/网址），位置与视觉权重最高；次行动不出现。
3. **文字少而大**：主标题 ≤8 词；3 秒阅读规则——扫一眼能懂；文字层级：标题 > 副文案 > 脚注。
4. **媒介决定构图**：先定尺寸再定构图（横版留两侧、竖版留上下、方形留中心）；不同媒介用同一视觉语言。
5. **tokens 派生**：配色/字体/间距全部引用 DESIGN.md；品牌元素（logo/主色）优先，风格库只借鉴构图。

## 工作流程

### 步骤 0：读取强度模式

- 读取 `.dreamspec/SKILLS.md`，确定 rigorous / balanced / light 裁剪范围。

### 步骤 1：确认需求（输入）

- 询问/确认：媒介与尺寸（网页 16:9 / 社媒 1:1、1.91:1、9:16 / 开屏 3:1、9:16 / 电商 4:5、1:1）、用途（活动/新品/促销/品牌）、CTA 与文案素材；
- 产物：需求卡（媒介清单 + 卖点 + CTA + 已有素材）。

### 步骤 2：定构图与视觉方向（动作）

- 按 references/banner-patterns.md 选构图模式（居中焦点/三分/对角/留白焦点/背景全幅）；
- 从 DESIGN.md 取色（或经 dream-style-library 定方向）；确定主视觉（产品图/插画/渐变/照片，优先真实素材）。

### 步骤 3：排版与层级（动作）

- 主标题 1 行（≤8 词，字号最大）；副文案 ≤2 行；CTA 按钮与标题同层级权重；
- 文字与背景对比 ≥4.5:1（标题 3:1 底线，建议 4.5:1）；CTA 用对比最强的主色。

### 步骤 4：多尺寸适配（产物）

- 一套主视觉适配需求清单中的全部尺寸（构图按媒介微调，不拉伸变形）；
- 产物：每个尺寸一张图 + 源文件（SVG/HTML 可编辑，位图导出 PNG 规格：尺寸/格式/压缩）。

### 步骤 5：检查与交付（产物）

- 快速反 slop 自检（参照 dream-ui-polish 清单）与尺寸清单核对；
- 产物：交付包（源文件 + 多尺寸导出 + 使用说明：放置位置/替换规则）。

## 验收标准

- [ ] 需求卡已确认（媒介/卖点/CTA/素材）
- [ ] 每张图单一视觉焦点 + 一个 CTA；无"信息堆砌"
- [ ] 主标题 ≤8 词；文字对比度达标（≥4.5:1 或注明豁免）
- [ ] 配色/字体引用 DESIGN.md tokens，无硬编码
- [ ] 需求清单中全部尺寸均已输出，且无拉伸变形
- [ ] 交付包含源文件（SVG/HTML）与多尺寸导出
- [ ] light 模式：单尺寸 + 快速自检即可

## 与其他技能的衔接

- 上游：dream-design-system（tokens）、dream-style-library（风格方向，可选）
- 下游：dream-review / dream-verify（验证门：尺寸齐全、tokens 一致、可渲染）
- 验证：light 模式冒烟（源文件可渲染）即可
- 强度模式：rigorous 全套多尺寸 + 使用说明；balanced 需求清单全尺寸；light 单尺寸
