# 横幅构图模式库（banner-patterns · references）

> 本文件由 dream-banner-design 构图与排版时按需加载。所有配色/字体取值来自 DESIGN.md tokens；数值基于常见媒介基准。

## 1. 媒介尺寸表

| 媒介 | 比例 | 典型尺寸 | 构图注意 |
|---|---|---|---|
| 网页横幅 | 16:9 | 1920×1080 / 1200×675 | 文字与 CTA 靠左或居中，右侧留视觉 |
| 社媒横向帖 | 1.91:1 | 1200×628 | 上下留白安全区（头像/文字遮挡区） |
| 社媒方形帖 | 1:1 | 1080×1080 | 中心构图最稳；四角留安全边距 |
| 社媒故事/竖版 | 9:16 | 1080×1920 | 上 1/3 主视觉、中 1/3 文案、下 1/3 CTA |
| App 开屏（横） | 3:1 | 1200×400 | 单行标题 + 右侧 CTA；左右留 logo 区 |
| App 开屏（竖） | 9:16 | 1080×1920 | 上视觉、中标题、下按钮（拇指区） |
| 电商主图 | 4:5 / 1:1 | 1000×1250 / 1000×1000 | 产品居中 + 卖点角标；避开平台标签区 |

安全区：所有尺寸保留 8% 边距作安全区，避免平台 UI（头像/按钮/角标）遮挡文字。

## 2. 构图模式（5 种）

### 居中焦点（Centered Focus）
- 主体/标题居中，背景简洁；适合品牌宣言、新品发布；
- 避坑：中心元素不要贴安全区边缘。

### 三分构图（Rule of Thirds）
- 主体放三分线交叉点，文字占剩余一栏；适合产品图 + 卖点；
- 避坑：三分线上的元素与文字不要互相压叠。

### 对角引导（Diagonal Flow）
- 视觉沿对角线流动（主体左上 → CTA 右下）；适合促销、活动；
- 避坑：对角线元素间距一致，避免中间断裂感。

### 留白焦点（Whitespace Focus）
- 大面积留白 + 极小主体/极简文字；适合高端、奢侈品；
- 避坑：留白 ≠ 空洞——必须有一个明确的视觉锚点。

### 背景全幅（Full-bleed）
- 图片/渐变铺满全幅，文字叠放其上；适合沉浸式品牌视觉；
- 避坑：文字区必须加遮罩（深色 30–50% 或浅色 60%）保证对比度。

## 3. 文字层级规则

- 主标题：1 行、≤8 词、字号最大（如 16:9 横幅 56–72px）；加粗，可含换行点；
- 副文案：≤2 行、24–28px；只补一句价值说明；
- 脚注/细节：12–14px、text-secondary；放角落不抢戏；
- 层级比：标题 : 副文案 : 脚注 ≈ 4 : 2 : 1；行数越少字号越大。

## 4. CTA 规则

- 一个图一个 CTA（按钮或网址或二维码，不并存两套）；
- CTA 位置：横版右下或居中下方；竖版底部（拇指区）；方形版主视觉旁；
- CTA 视觉权重最高：用主色实底 + 白色文字；按钮 ≥40px 高；
- 按钮文案：动词开头（"立即预约""查看详情"），≤6 字；禁用"点击这里"。

## 5. 多尺寸适配

- 一套主视觉 + 每尺寸重构图（不是拉伸）：横版裁两侧、竖版裁上下、方形裁中心；
- 文字按尺寸重新排版（字号/行数随尺寸变化），不缩放已有文字图层；
- 同一视觉语言：配色/字体/留白规则在所有尺寸一致；
- 交付清单：源文件（SVG/HTML）+ 每尺寸 PNG 导出（注明导出规格）。

## 6. 避坑清单

- ❌ 一个图塞多个卖点/多个 CTA；❌ 文字被平台 UI 遮挡（未留安全区）；
- ❌ 低对比度文字（浅字浅底）；❌ 产品图拉伸变形；❌ 渐变超过 2 色且透明度过高；
- ❌ 用 emoji 当 CTA 图标；❌ 主视觉与品牌主色冲突；
- ✅ 每张图先自问："3 秒内能看懂卖点吗？"
