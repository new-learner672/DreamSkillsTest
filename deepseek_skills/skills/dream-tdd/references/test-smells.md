# 测试坏味道清单（references）

> 本文件由 dream-tdd 按需加载。写完测试后用此清单自检；测试也是代码，坏味道一样要修。

## 1. 行为类坏味道

| 坏味道 | 信号 | 修复 |
|---|---|---|
| 测试内部实现 | 改实现导致测试失败（行为没变） | 断言公共行为/输出，不摸内部状态 |
| 断言过弱 | 只断言"没抛错"或返回非空 | 断言具体值/结构/副作用 |
| 断言过强 | 耦合无关细节（精确到毫秒/行号） | 用容差、等价类断言 |
| 空测试 | `it('...')` 无断言体 | 删除或补真实断言 |
| 测试依赖顺序 | 单独跑失败、一起跑通过 | 每个测试独立准备数据，不依赖执行顺序 |
| 测试有共享可变状态 | 改一个测试影响另一个 | 每个测试独立 setup/teardown |

## 2. 结构类坏味道

| 坏味道 | 信号 | 修复 |
|---|---|---|
| 测试金字塔倒置 | 全是 E2E，没有单元测试 | 逻辑下沉为可单测函数；E2E 只留关键流程 |
| 一个测试测多件事 | 一个用例里断言 5 个行为 | 拆成多个测试（一行为一测试） |
| 重复 setup 巨大 | 每个测试复制 20 行准备代码 | 提取工厂/夹具，但保持每个测试可读 |
| 测试代码不可读 | 命名含糊、魔法值满天飞 | 行为化命名 + 具名常量 |
| 断言埋在深层 helper | 测试里看不到断言 | 断言写在测试体内，helper 只做准备 |

## 3. 可靠性类坏味道

| 坏味道 | 信号 | 修复 |
|---|---|---|
| 偶发失败（flake） | 跑 10 次挂 1 次 | 消除时序/随机/网络依赖；失败可复现再修 |
| 睡眠等待 | `sleep(1000)` 等异步 | 用轮询/await 事件/虚拟时钟 |
| mock 过度 | 什么都 mock，测试失去意义 | 只 mock 外部边界（IO/网络/时间） |
| mock 与真实行为不符 | mock 永远返回成功 | mock 覆盖真实返回路径与异常路径 |
| 测试修改全局 | 测试里改 env/全局并污染后续 | 用临时 env + 恢复，或注入 |
| 覆盖假象 | 断言多但都测同一路径 | 检查分支/异常路径是否真的被覆盖 |

## 4. 强度模式下的自检侧重

- rigorous：三类坏味道全部自检，重点检查边界与异常路径覆盖；
- balanced：重点检查行为类 + 可靠性类（flaky 最伤信任）；
- light：至少避免"空测试"与"断言过弱"两条（否则测试无价值）。

## 5. 自检动作

```
□ 每个测试：一个行为、一个断言主题
□ 改实现不改变行为时，测试应不受影响（可验证：重构后全绿）
□ 单独运行每个测试都能通过（不依赖顺序）
□ 无 sleep 等待、无全局污染
□ mock 仅用于外部边界，且覆盖成功+失败路径
□ 单元/接口/E2E 比例合理（金字塔）
```
