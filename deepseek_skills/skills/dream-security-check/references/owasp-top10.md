# OWASP Top 10 核对清单（dream-security-check 的 references）

> 用途：交付前逐类核对。每类给"是什么 / 怎么查 / 常见修复"。核对结论写入 security-report.md。
> 说明：按 OWASP Top 10 常见条目整理（注入、认证、数据、XSS、访问控制、配置、组件、日志维度），并补充 Web 工程最常踩的 CSRF 与敏感信息泄露检查项。

## 1. 注入（Injection：SQL / NoSQL / 命令）
- 是什么：用户输入拼接进查询/命令执行。
- 怎么查：搜索字符串拼接 SQL/命令的代码路径；检查 ORM 是否使用参数化。
- 修复：参数化查询 / 预编译语句 / 白名单校验；禁止 eval/exec 拼接用户输入。

## 2. 认证与会话失效（Broken Authentication）
- 是什么：弱口令策略缺失、令牌未过期、会话固定。
- 怎么查：检查登录流程、令牌签发/过期逻辑、会话存储。
- 修复：强口令策略 + 失败限速；令牌短期过期 + 刷新机制；会话失效后服务端销毁。

## 3. 敏感数据暴露（Sensitive Data Exposure）
- 是什么：密码/令牌/个人数据明文存储或传输、写入日志。
- 怎么查：grep 硬编码密钥/密码；检查日志输出；检查传输是否 HTTPS。
- 修复：密钥入环境变量/密钥管理服务；密码哈希（bcrypt/argon2）；日志脱敏；全站 HTTPS。

## 4. XSS（跨站脚本）
- 是什么：未转义的用户输入渲染进页面执行脚本。
- 怎么查：检查动态 HTML 插入点（innerHTML、v-html、dangerouslySetInnerHTML）。
- 修复：默认转义输出；避免危险 API；CSP 头收紧；输入校验。

## 5. 访问控制失效 / 越权（Broken Access Control）
- 是什么：未校验权限即访问资源（水平/垂直越权）。
- 怎么查：每个受保护接口/操作是否校验当前用户身份与角色；IDOR（直接改 ID 访问他人资源）。
- 修复：服务端统一鉴权中间件；资源归属校验；默认拒绝。

## 6. CSRF（跨站请求伪造）
- 是什么：第三方站点诱导已登录用户发起请求。
- 怎么查：状态变更请求（POST/PUT/DELETE）是否有 CSRF 令牌 / SameSite Cookie。
- 修复：CSRF Token 校验；Cookie SameSite=Strict/Lax；敏感操作二次确认。

## 7. 安全配置错误（Security Misconfiguration）
- 是什么：默认口令、调试模式开启、错误信息泄露堆栈、目录列表开放。
- 怎么查：检查运行环境配置（debug=true？）、错误页是否泄露内部细节、CORS 是否过宽。
- 修复：生产环境关闭调试；错误信息脱敏；CORS 白名单；移除默认凭据。

## 8. 已知漏洞组件（Vulnerable & Outdated Components）
- 是什么：依赖库存在已知 CVE。
- 怎么查：`npm audit` / `pip-audit` / deps.dev 扫描依赖。
- 修复：升级到安全版本；无法升级则记录风险并评估缓解。

## 9. 不安全反序列化 / SSRF（如适用）
- 是什么：反序列化不可信数据；服务端请求被引导到内网。
- 怎么查：检查反序列化入口（pickle / 敏感处 JSON.parse）；检查 URL 抓取功能。
- 修复：仅反序列化可信数据；URL 白名单 + 禁止内网地址。

## 10. 日志与监控失效（Logging & Monitoring）
- 是什么：无日志、无告警，攻击不可见。
- 怎么查：关键操作（登录/权限变更/支付）是否有日志；是否脱敏。
- 修复：结构化日志 + 关键事件埋点；敏感字段脱敏；告警规则。
