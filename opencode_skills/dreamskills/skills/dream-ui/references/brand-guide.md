# 品牌体系指南（整合自 UI UX Pro Max brand skill）

**唯一事实源**：`docs/brand-guidelines.md`。所有品牌资产（design-tokens.json、design-tokens.css）由它同步生成，禁止多处手工维护。

## 1. 品牌指南结构（brand-guidelines-starter 模板）

1. **品牌基础**：使命、愿景、价值观、品牌个性（选 3-5 个形容词）
2. **视觉识别**：Logo 变体与最小尺寸、配色（主色/辅色/中性色及比例）、字体体系（标题/正文/备用）、图形元素、摄影风格
3. **声音框架（Voice）**：语气四维定位——正式↔随意、热情↔克制、专业↔亲切、简洁↔详尽；每维一句话示例
4. **消息框架（Messaging）**：价值主张一句话、目标受众、核心消息层级（主标语/副标语/支持点）
5. **资产规范**：命名、尺寸、格式、存放路径

## 2. 色彩管理规则

- 主色 ≤2 个 + 强调色 1 个 + 中性色系（灰阶带色相倾向，避免纯 #000/#fff 极端）
- 每个颜色记录：hex + 用途 + 对比度达标前景色
- 色板变更必须同步所有资产并过一致性检查

## 3. 字体规范

- 标题字体 + 正文字体成对记录（可查 `typography.csv` 74 组配对）
- 记录：字号层级（h1-h4 + body + caption）、行高、字重可用范围
- 网页需记录加载策略（子集化、font-display: swap）

## 4. Logo 使用规则

- 最小尺寸（如 32px 高度）、安全区（Logo 高度的 0.5 倍）、禁止变体（拉伸/改色/加阴影/旋转）
- 深色背景用反白版本；记录哪些版本在哪些场景可用

## 5. 一致性检查清单（audit 用）

- [ ] 颜色是否全部来自色板（无裸 hex）
- [ ] 字体是否与规范一致（无未授权字体）
- [ ] 语气是否符合声音框架
- [ ] Logo 是否遵守使用规则
- [ ] 资产命名/尺寸/格式是否符合规范
- [ ] 消息是否使用核心消息层级

## 6. 审批清单（approval）

- 变更类型（新建/修改/废弃资产）
- 影响范围（哪些页面/物料受影响）
- 审批人记录（谁批准的、何时）

## 7. 自动化

- 资产校验：命名（kebab-case）、尺寸、格式、路径合规
- 颜色提取：从图片提取主色并对比现有色板（漂移检测）
- 同步：编辑 brand-guidelines.md → 生成 design-tokens.json + design-tokens.css
