# 40 门反 AI 味检查清单（UI Slop Checklist）

> 交付前逐项自检；任一红灯即返工。来源整合：Hallmark 57 门精简 + Taste-Skill 硬规则 + UI UX Pro Max 交付清单。

## A. 指纹级硬规则（红灯 = 打回）

1. [ ] 无 em-dash 破折号（—），全部替换为中文破折号或其他表达
2. [ ] 无 emoji 充当图标（须用 SVG/图标库）
3. [ ] 无"AI 紫粉渐变"（紫 #7C3AED → 粉 #EC4899 组合，金融/企业场景绝对禁止）
4. [ ] 无默认 Tailwind 色板原样输出（未定制化）
5. [ ] 无"居中白卡片 + 三个功能图标 + 渐变按钮"套版英雄区

## B. 结构与布局

6. [ ] 页面骨架（macrostructure）与同类模板不同，两个 brief 产出两个骨架
7. [ ] 无 12 列等宽卡片矩阵的滥用（卡片用在不同布局节奏）
8. [ ] 首屏有明确的视觉焦点（一个主角元素）
9. [ ] 响应式断点覆盖 ≥3 档（移动/平板/桌面），无横向滚动
10. [ ] 页脚完整（版权/联系/导航），非"© 2026"敷衍

## C. 色彩与对比度

11. [ ] 正文对比度 ≥ 4.5:1，大字 ≥ 3:1
12. [ ] 调色板 ≤5 色 + 中性色系，主色使用比例 <10%
13. [ ] 暗色模式是设计而非反色（背景不用纯黑 #000）
14. [ ] 色彩传递信息时不依赖颜色（色盲友好，配图标/文字）

## D. 字体与排版

15. [ ] 字体配对有主次（标题/正文各司其职），非全站一个默认字体
16. [ ] 行高正文 1.5-1.75，标题 1.1-1.3
17. [ ] 每行 45-75 字符（中文约 22-35 字）
18. [ ] 字号层级 ≤5 级，层级差有节奏（非 1px 微调）
19. [ ] 无全大写长段落、无过度加粗

## E. 间距与节奏

20. [ ] 间距用 4/8 倍数刻度，非随意数值
21. [ ] 留白有节奏（呼吸感 vs 密度旋钮一致）
22. [ ] 相关元素邻近、不相关元素分离（格式塔）

## F. 动效与交互

23. [ ] hover 过渡 150-250ms，缓动曲线一致（如 cubic-bezier）
24. [ ] 动效强度匹配 MOTION_INTENSITY 旋钮
25. [ ] 尊重 prefers-reduced-motion（用户关动效时全静）
26. [ ] 无"每张卡片都 float-up"的机械入场动画
27. [ ] 按钮/链接有 hover、focus、active、disabled 四态
28. [ ] focus 可见（键盘可达性）

## G. 文案与内容

29. [ ] 无"Lorem ipsum"残留、无占位注释（如 // TODO: add content）
30. [ ] 无 AI 味套话（"Elevate your experience" "Unleash the power" 等）
31. [ ] 按钮文案是动词短语，非"点击这里/提交"
32. [ ] 错误/空状态有真实文案与指引

## H. 性能与工程（与 dream-verify 联动）

33. [ ] 首屏 JS < 300KB
34. [ ] 图片有尺寸属性、lazy 加载、现代格式（WebP/AVIF）
35. [ ] 无布局抖动（图片/广告位预留空间，CLS < 0.1）
36. [ ] CSS 用变量承载设计 token，无魔法数值散落

## I. 可访问性

37. [ ] 语义化标签（nav/main/article/button 不混用 div）
38. [ ] 图片有 alt（装饰图留空）
39. [ ] 表单有 label 关联
40. [ ] 关键操作可纯键盘完成
