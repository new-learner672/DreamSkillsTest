# Dreamskills 安装部署

Dreamskills 采用 **Anthropic Agent Skills 规范**（SKILL.md + frontmatter），提供三种部署方式：**npm CLI（参考 OpenSpec 终端部署，推荐）**、一键脚本、插件市场。适配 Windows / Linux / macOS × x86_64 / arm64。

## 0. 支持矩阵

| 维度 | 支持 |
|---|---|
| 操作系统 | Windows / Linux / macOS |
| CPU 架构 | x86_64 / arm64（CLI 与技能均为纯解释型脚本，架构无关） |
| 运行时 | Node ≥18（CLI）；Python 3（可选，dream-ui 检索加速，缺省走 CSV 直读降级） |
| 目标宿主 | opencode / codex / claude code / cursor 等 14+（全局或项目级） |

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| CLI 运行时 | Node.js ≥18（仅标准库，零 npm 依赖，任何架构官方发行版均可） |
| 技能本体 | 无硬性要求（纯 Markdown 技能包） |
| 可选加速 | Python 3（dream-ui BM25 检索；无则自动降级 CSV 直读） |
| 磁盘 | < 2 MB（含 dream-ui 1.4MB 设计数据资产） |

## 2. 安装方式

### 2.1 方式 A：npm CLI 终端部署（参考 OpenSpec 模式，推荐）

OpenSpec 用 `npx @fission-ai/openspec` 一条命令部署；Dreamskills 提供同等体验的 `dreamskills-cli`：

```bash
# 免安装体检（自动输出 OS/架构/宿主/依赖状态）
npx dreamskills-cli doctor

# 一键安装全部 13 技能（自动检测宿主：opencode/codex/claude code）
npx dreamskills-cli install

# 指定宿主 / 全局 / 单技能 / 覆盖
npx dreamskills-cli install --target codex
npx dreamskills-cli install --target opencode,codex --global
npx dreamskills-cli install --skill dream-ui --force

# 初始化项目（specs/ + constitution.md，等价 /dream-init）
npx dreamskills-cli init

# 本地仓库直接运行（无需 npm）
node cli/index.js doctor
npm install -g dreamskills-cli   # 或全局安装后使用 dreamskills 命令
```

arm64 平台（Apple Silicon / AWS Graviton / 树莓派）：Node.js 官方对 darwin-arm64、linux-arm64 有原生发行版，CLI 无需任何改动即可运行；`dreamskills doctor` 会打印实际架构供确认。

### 2.2 方式 B：一键安装脚本（无 Node 环境时）

```powershell
# Windows（PowerShell 5.1+，脚本自动检测 OS/架构）
powershell -ExecutionPolicy Bypass -File install.ps1                  # 项目级（opencode + codex）
powershell -ExecutionPolicy Bypass -File install.ps1 -Global          # 全局
powershell -ExecutionPolicy Bypass -File install.ps1 -Target codex    # 仅 codex
powershell -ExecutionPolicy Bypass -File install.ps1 -Skill dream-ui  # 仅单技能

# Linux/macOS（bash，含 OS/架构检测输出）
./install.sh                 # 项目级（opencode + codex）
./install.sh --global        # 全局
./install.sh --target opencode --skill dream-ui
```

安装行为（两种脚本一致）：
- **opencode 项目级**：`<项目>/.opencode/skills/<skill>/SKILL.md`（含 commands/、hooks/）
- **opencode 全局**：`~/.config/opencode/skills/`（Linux/macOS）或 `%APPDATA%/opencode/skills/`（Windows）
- **codex 项目级**：`<项目>/.codex/skills/<skill>/SKILL.md`；**codex 全局**：`~/.codex/skills/`
- 已存在同名技能时跳过（保护本地修改），不覆盖（CLI 加 `--force` 可覆盖）
- **dream-ui 全量资产随技能复制**：`data/*.csv`（约 1.4MB 设计数据库）+ `references/` + `scripts/`（可选 Python 检索）

### 2.3 方式 C：Claude Code 插件市场 / 手动复制

```bash
# Claude Code：本地插件安装（插件清单 .claude-plugin/plugin.json）
/plugin install dreamskills@D:\DeepSeekHarnessTest\opencodeskills\dreamskills

# 手动复制（任意宿主，无 Node 无脚本环境）
#   opencode 项目级:  Copy-Item -Recurse dreamskills\skills\* "<项目>\.opencode\skills\"
#   codex 项目级:     Copy-Item -Recurse dreamskills\skills\* "<项目>\.codex\skills\"
#   斜杠命令与钩子:   Copy-Item dreamskills\commands\* "<项目>\.opencode\commands\"
#   Cursor / Gemini CLI / Copilot CLI: 复制到对应全局 skills 目录即可
```

### 2.4 方式 D：仅作提示词参考（无宿主）

直接让 AI 阅读本仓库的 SKILL.md 与 references 文件，或人工遵循文档流程，不依赖任何宿主机制。

## 3. 初始化项目

```bash
npx dreamskills-cli init     # CLI 方式（推荐）
/dream-init                 # Claude Code 插件方式
# 或直接告诉 AI："请用 dream-spec 技能初始化本项目"
```

初始化产出：
- `specs/` 目录（现状规格，空）
- `constitution.md`（项目宪法，轻量 6 条，可改）
- `changes/` 目录（变更提案区）
- `.dreamskills/` 元数据（可选）

## 4. 验证安装

```bash
# 列出已加载技能（Claude Code）
/plugin list
# 或问 AI："你现在有哪些 dreamskills 技能可用？"——应能列出 13 个技能名
```

自检清单：
- [ ] `dream-spec` 能被"创建一个变更提案"触发
- [ ] `dream-tdd` 能被"先写测试"触发
- [ ] `dream-ui` 能被"设计一个登录页"触发
- [ ] `dream-verify` 能被"检查性能/可访问性"触发

**opencode / codex 专项验证**：
- opencode：会话中问"你有哪些 dreamskills 技能可用？"（应列出 13 个）；再问"用 dream-ui 给我生成一个 SaaS 登录页设计系统"，应看到它读取 `data/products.csv`、`data/styles.csv` 等资产
- codex：同上；若项目含 Python 3，可让 AI 执行 `python skills/dream-ui/scripts/search.py "saas login" --design-system` 验证检索管线；无 Python 则验证 CSV 直读降级路径

## 5. 升级与卸载

### 5.1 升级

- 重新安装即升级：技能数据（`specs/`、`changes/`）与技能本体分离，覆盖安装不影响项目数据
- CLI：`npx dreamskills-cli install --force`（强制覆盖已装技能）
- 脚本：先卸载再安装，或手工删除宿主中的 `dream-*` 目录后重装

### 5.2 卸载方式

**方式一：CLI 卸载（推荐，跨平台）**

```bash
npx dreamskills-cli uninstall                        # 卸载项目级全部 13 技能（opencode + codex + claude）
npx dreamskills-cli uninstall --target codex         # 仅卸载 codex
npx dreamskills-cli uninstall --global               # 卸载全局安装
npx dreamskills-cli uninstall --skill dream-ui       # 仅卸载单个技能
npx dreamskills-cli uninstall --target all --dir <项目路径>   # 指定目录
```

**方式二：脚本卸载**

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall                       # 项目级全部
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall -Global               # 全局全部
powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall -Target codex -Skill dream-ui

# Linux/macOS
./install.sh --uninstall
./install.sh --uninstall --global
./install.sh --uninstall --target codex --skill dream-ui
```

**方式三：手动卸载**

删除宿主 skills 目录中的 `dream-*` 文件夹即可：

| 宿主 | 项目级 | 全局 |
|---|---|---|
| opencode | `<项目>/.opencode/skills/dream-*` | `~/.config/opencode/skills/dream-*`（Windows 为 `%APPDATA%/opencode/skills/`） |
| codex | `<项目>/.codex/skills/dream-*` | `~/.codex/skills/dream-*` |
| claude code | `<项目>/.claude/skills/dream-*` | `~/.claude/skills/dream-*` |

斜杠命令与钩子：删除 `<宿主>/commands/dream-*.md` 与 `<宿主>/hooks/session-start.md`（如已复制）。

**方式四：Claude Code 插件卸载**

```bash
/plugin uninstall dreamskills@your-marketplace
```

### 5.3 卸载保留策略

- 卸载**只删除技能文件**，以下用户数据**永久保留**（可继续作普通文档使用）：
  - `specs/`（含 constitution.md、adr/）、`changes/`、`archive/`
  - `research/`、`brainstorm/`、`.dreamskills/learnings.md`
  - dream-ui 生成的 `design-system/` 目录
- 如需彻底清空，手动删除上述目录即可

## 6. dream-ui 数据资产说明

- 位置：`dreamskills/skills/dream-ui/data/`（13 个主 CSV + `stacks/` 22 个技术栈 CSV，约 1.4MB）
- 许可：整合自 nextlevelbuilder/ui-ux-pro-max-skill（MIT），详见 `data/README.md`
- 检索：Python 3 标准库脚本（`scripts/search.py`，零依赖）；无 Python 时模型直接 grep/读 CSV（等效降级路径）
- 卸载注意：数据随技能目录一并删除，不影响项目代码
